Om innholdet

Oppgavene er laget med utgangspunkt i undervisningsmaterialet Kjemien Stemmer kapittel 1 og 2, Sikkerhet på lab og det opplastede periodesystemet. Spørsmålene er egne formuleringer og erstatter ikke lærebok, sikkerhetsdatablader eller lokale laboratorieinstrukser.

Fremtidige kapitler kan legges til ved å oppdatere denne HTML-filen på GitHub Pages. Innholdet krever ingen innlogging eller server.
